# TICKET-UT-003

# MarkItDownManager Component Test 구현

## Depends On

```text
TICKET-UT-002
```

---

## 목표

실제 MarkItDown executable에 의존하지 않고 `MarkItDownManager`의 conversion lifecycle 및 오류 처리를 검증한다.

---

## 테스트 대상

실제 구현에서 다음 동작을 확인한다.

```text
convert()
isRunning()

processFinished()
processError()

collectStandardError()
reportProcessFailure()

decodedStandardError()
diagnosticDetails()
```

함수의 실제 visibility 및 responsibility는 source 기준으로 판단한다.

private function을 직접 테스트하지 않는다.

---

## 필수 Scenario

### 정상 변환

Fake process:

```text
start success
exitCode = 0
stdout = valid Markdown
```

Expected:

```text
conversion success
Markdown result 전달
running state 종료
```

---

### AlreadyRunning

```text
첫 번째 conversion 실행 중
        ↓
두 번째 convert 요청
```

Expected:

```text
ConversionError::AlreadyRunning
```

실제 구현 계약을 확인한다.

---

### ExecutableNotFound

Resolver 결과:

```text
empty / invalid executable
```

Expected:

```text
ExecutableNotFound
```

---

### FailedToStart

Fake process가 start failure를 발생시킨다.

Expected:

```text
FailedToStart
```

---

### Crashed

Fake process:

```text
CrashExit
```

Expected:

```text
Crashed
```

---

### NonZeroExit

Fake process:

```text
NormalExit
exitCode != 0
```

Expected:

```text
NonZeroExit
```

stderr가 diagnostic에 반영되는지도 실제 contract에 따라 검증한다.

---

### EmptyOutput

```text
exitCode = 0
stdout = empty
```

Expected:

```text
EmptyOutput
```

---

### ProcessFailure

실제 enum 및 error mapping에 해당하는 process error가 존재하면 검증한다.

---

## QSignalSpy

public contract가 signal이면 다음과 같은 방식으로 검증한다.

```cpp
QSignalSpy startedSpy(...);
QSignalSpy finishedSpy(...);
QSignalSpy failedSpy(...);
```

signal argument가 contract 일부인 경우 argument도 확인한다.

---

## 추가 검증

```text
conversion 시작 → isRunning == true
conversion 종료 → isRunning == false
error 종료 → isRunning == false
```

state cleanup을 반드시 검증한다.
