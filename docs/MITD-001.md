# MITD-001 — MainWindow 기본 UI 구성

## 구현 내용

- 애플리케이션 제목을 `MarkItDown Viewer`로 설정했다.
- 메뉴 바에 `File`, `Edit`, `View`, `Help` 메뉴를 구성했다.
- 기본 툴바에 `Open`, `Convert`, `Save` 액션을 배치했다.
- 중앙 영역에 수평 `QSplitter`를 배치하고, 왼쪽에는 `QPlainTextEdit` 기반 Markdown 편집기, 오른쪽에는 `QTextBrowser` 기반 Markdown 미리보기를 구성했다.
- 스플리터 양쪽 영역이 완전히 접히지 않도록 설정해 두 영역을 항상 확인하고 크기를 조절할 수 있게 했다.
- 상태 표시줄의 초기 메시지를 `Ready`로 설정했다.

## 제외 범위

티켓 요구사항에 따라 `Open`, `Convert`, `Save` 액션의 실제 동작과 파일 변환 로직은 연결하지 않았다.

## 확인 방법

애플리케이션 실행 후 다음 항목을 확인한다.

1. 메뉴 바에 네 개 메뉴가 표시된다.
2. 툴바에 세 개 액션이 표시된다.
3. 중앙 구분선을 좌우로 끌어 편집기와 미리보기의 크기를 조절할 수 있다.
4. 상태 표시줄에 `Ready`가 표시된다.
