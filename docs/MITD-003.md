# MITD-003 — 단일 파일 Open 기능

## 구현 내용

- 메뉴와 툴바가 공유하는 `Open` 액션을 단일 파일 선택 대화상자에 연결했다.
- `QFileDialog::getOpenFileName()`을 사용해 한 번에 파일 하나만 선택하도록 했다.
- 지원 확장자는 `pdf`, `docx`, `pptx`, `xlsx`, `xls`, `html`, `htm`, `csv`, `json`, `xml`, `txt`로 제한했다.
- 파일 선택 시 기존 `Document`를 초기화하고, 선택한 파일의 절대 경로를 `sourceFilePath`에 저장한 뒤 상태를 `DocumentStatus::Ready`로 변경한다.
- 창 제목은 `MarkItDown Viewer - <파일명>`, 상태 표시줄은 `<파일명> | Ready` 형식으로 갱신한다.
- 파일 선택을 취소하면 현재 문서와 UI 상태를 변경하지 않는다.

## 동작 범위

이 기능은 파일 경로만 등록한다. 선택한 파일의 내용을 읽거나 MarkItDown 변환을 시작하지 않는다.

## 확인 방법

1. 애플리케이션을 실행하고 메뉴 또는 툴바의 `Open`을 선택한다.
2. 지원 형식의 파일 하나를 선택한다.
3. 창 제목과 상태 표시줄에 선택한 파일명이 표시되는지 확인한다.
4. `Open` 대화상자를 다시 열어 취소하고 기존 문서 표시가 유지되는지 확인한다.
